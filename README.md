# 观看 MV (watch-mv)

Songloft 插件：一键在 **哔哩哔哩 / 优酷 / 腾讯视频 / 爱奇艺 / 芒果TV** 搜索当前歌曲的 MV。

## 功能

- 搜索词 = `歌名 + 歌手 + MV`，五个站点一键直达；
- **新标签页跳转**（默认，100% 可用）或 **内嵌面板**（实验性：B站/腾讯/爱奇艺等设了防嵌入，内嵌失败时页面内提供跳转按钮）；
- 支持手动输入歌名/歌手，或从曲库列表选歌（带过滤）；
- 宿主若提供播放器桥接（`SongloftPlugin.getPlayerInfo`）可自动带出当前歌曲，没有则静默跳过；
- 站点多选与打开方式保存在浏览器本地。

## 安装

```
下载 https://github.com/514475844/songloft-plugin-watch-mv/releases/latest/download/watch-mv.jsplugin.zip
上传到 Songloft 插件管理页即可
```
